# Cookeo Bridge

Recipe web interface, private personal cloud recipes, regional account setup and MQTT telemetry for Home Assistant.

Created to make a cooker bought for another distribution market usable when the local app catalog prevents registration. Verified with Moulinex Cookeo Infinity CE9821F0 using the Belgian My Moulinex context and an English/Czech interface.

Existing cloud bindings are reused after sign-in; pairing is optional. Requires the manufacturer's cloud. Cooking starts on the appliance.

See **Documentation** for setup, migration without re-pairing, recipe privacy and Bluetooth limitations.

[Project and Czech instructions](https://github.com/AidenShaw2020/cookeo-bridge)
